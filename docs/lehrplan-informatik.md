## Aufbau

- Gruppen: Grundlagen, Turtle, Denken.
- Jede Seite hat eine Lektion, Übungsaufgaben und ein Code-Labor. Das Labor führt Python-Code in einem eigenen kleinen Interpreter aus (kein `eval`, kein echtes Python). Es versteht nur die Teilmenge, die die Seiten brauchen.
- Missionen vergleichen das gezeichnete Bild mit dem Zielbild der Musterlösung (Raster, kein Pixelvergleich). Bei Schleifen-Missionen muss das Wort `for` im Code stehen.
